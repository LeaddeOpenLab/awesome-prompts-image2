```text

บุคคลและสีหน้า:
เอียงใบหน้าไปทางขวาล่างของภาพ สายตาทอดมองลงไปยังมือที่จับผ้าอยู่ สีหน้าสงบนิ่งค่อนไปทางมุมข้าง โครงหน้าเรียวรูปไข่ ดวงตาเรียวยาวที่หลุบลง สันจมูกโด่งเรียว ริมฝีปากสีอ่อนเผยอออกเล็กน้อย ผมสีน้ำตาลเข้มเปียกน้ำยาวเลยไหล่แสกข้าง มีปอยผมเส้นบางๆ แนบติดกับแก้มและลำคอ

พันผ้าผืนบางสีขาวไร้สายคล้ายชุดเดรสยาวตั้งแต่ช่วงอก โดยมีรอยจับจีบแนวทแยงพาดทับลำตัวและเรียวขา ยืนเท้าเปล่าในน้ำตื้น แขนขวาของตัวแบบทอดลงข้างลำตัว มือซ้ายจับผ้าบริเวณด้านหน้าเอว ยื่นขาข้างหนึ่งไปข้างหน้าเล็กน้อย

พื้นหลังและแสง:
ท้องฟ้าสีน้ำเงินอมม่วงทางด้านซ้ายบนของภาพมีจันทร์เสี้ยวบางๆ เส้นขอบฟ้าทางขวามีแสงอาทิตย์อัสดงสีส้ม ครึ่งล่างเป็นผิวน้ำทะเลและโขดหินสีดำ แสงอาทิตย์ตกต่ำจากด้านหลังขวาของภาพส่องขอบสีทองเรืองรองให้กับผ้าเปียกและเรือนร่าง ด้านหน้าได้รับแสงทไวไลท์สีฟ้าอ่อนนุ่มนวล

องค์ประกอบภาพและกล้อง:
```
